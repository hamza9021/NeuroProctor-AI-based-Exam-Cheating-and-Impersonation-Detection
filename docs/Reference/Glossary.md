# Glossary

This document defines terminology used throughout the NeuroProctor project.

## A

**Admin**
- System administrator role with full system access
- Can manage users, verify invigilators, and oversee exams

**AI Pipeline**
- Sequence of AI processing stages applied to video frames
- Includes YOLO detection, DeepSORT tracking, pose estimation, head pose estimation, and phone detection

**ArcFace**
- Face recognition model used for generating face embeddings
- Produces 512-dimensional feature vectors

**Association**
- Process of linking detected objects (e.g., phones) to person tracks
- Uses geometric metrics, pose keypoints, and temporal tracking

**ASGI**
- Asynchronous Server Gateway Interface
- Python standard for async web servers (used by FastAPI)

---

## B

**Bounding Box**
- Rectangular box around detected objects
- Defined by coordinates (x1, y1, x2, y2)

**Backend (Express)**
- Node.js/Express backend application
- Handles business logic, data persistence, and API endpoints

---

## C

**Cloudinary**
- Cloud-based image and video storage service
- Used for storing profile images and exam videos

**COCO Keypoints**
- 17 standard keypoints for human pose estimation
- Includes nose, eyes, ears, shoulders, elbows, wrists, hips, knees, ankles

**Confidence Score**
- Probability that a detection is correct (0.0 to 1.0)
- Used to filter low-confidence detections

**CORS**
- Cross-Origin Resource Sharing
- HTTP header-based mechanism for cross-origin requests

---

## D

**DeepSORT**
- Object tracking algorithm
- Combines Kalman filtering with Hungarian algorithm for assignment
- Provides stable track IDs across frames

**Detection**
- Identified object in a frame with bounding box and confidence
- Produced by YOLO object detection

---

## E

**Embedding**
- Feature vector representing a face
- 512-dimensional vector generated by ArcFace
- Used for face matching and identification

**Exam Session**
- Specific instance of an exam
- Has unique session code, invigilator assignment, and status

**Express**
- Node.js web application framework
- Used for the Backend application

---

## F

**FastAPI**
- Modern Python web framework for building APIs
- Used for the AI Services application

**Face Enrollment**
- Process of registering a student's face with multiple poses
- Includes front, left, right, up, and down poses

**Frame**
- Single image from a video
- Processed individually by the AI pipeline

**FrameContext**
- Shared data object passed through AI pipeline stages
- Contains frame, detections, tracks, poses, and other data

**Frontend**
- React-based user interface application
- Provides UI for users to interact with the system

---

## H

**Head Pose**
- Orientation of a person's head
- Represented by yaw, pitch, and roll angles (in degrees)

**HttpOnly Cookie**
- Cookie that cannot be accessed via JavaScript
- Used for JWT tokens to prevent XSS attacks

---

## I

**InsightFace**
- Face recognition library
- Provides face detection and embedding generation

**Invigilator**
- Exam proctor role
- Can create exams, manage sessions, and upload videos for analysis

**IOU**
- Intersection over Union
- Metric for measuring overlap between bounding boxes
- Used in NMS and object association

---

## J

**JWT**
- JSON Web Token
- Used for authentication and authorization
- Contains user ID, email, name, and role

---

## K

**Kalman Filter**
- Algorithm for estimating object state
- Used in DeepSORT for predicting object position

**Keypoint**
- Specific point on a human body (e.g., nose, wrist)
- Used in pose estimation

---

## M

**Mongoose**
- MongoDB object modeling tool for Node.js
- Used by Backend (Express) for database operations

**Motor**
- Async MongoDB driver for Python
- Used by AI Services for database operations

**MongoDB**
- NoSQL database used by the system
- Stores users, exams, sessions, video analyses, and students

---

## N

**NMS**
- Non-Maximum Suppression
- Algorithm to remove duplicate detections
- Uses IOU threshold to filter overlapping boxes

---

## O

**ONNX Runtime**
- Open Neural Network Exchange runtime
- Used for running AI models efficiently

---

## P

**Person Track**
- Tracked person across video frames
- Has stable track ID and bounding box

**Phone Track**
- Tracked phone across video frames
- Has temporal confirmation and student association

**Pose**
- Configuration of human body keypoints
- Used for face enrollment and behavior analysis

**Pose Estimation**
- Process of estimating human body keypoints
- Uses YOLO Pose model

**Pydantic**
- Data validation library for Python
- Used for request/response validation in FastAPI

---

## R

**React**
- JavaScript library for building user interfaces
- Used for the Frontend application

**ROI**
- Region of Interest
- Specific area of an image for focused processing
- Used in phone detection within person bounding boxes

**Role**
- User type with specific permissions
- Roles: admin, invigilator

---

## S

**Session Code**
- Unique identifier for an exam session
- Used to link videos to specific exam sessions

**Socket.IO**
- Library for real-time bidirectional communication
- Used for progress updates during video processing

**Student**
- Person enrolled in the system with face embeddings
- Can be monitored during exams

---

## T

**Temporal Smoothing**
- Technique to reduce noise in time-series data
- Used for head pose angles using exponential moving average

**Temporal Tracking**
- Tracking objects across time (frames)
- Used for phone confirmation and expiration

**Track ID**
- Stable identifier assigned to a tracked object
- Remains consistent across frames

---

## U

**Ultralytics**
- Company behind YOLO models
- Provides YOLOv8 implementation

---

## V

**Video Analysis**
- Record of video processing results
- Contains original and processed video URLs, status, and metadata

**Vite**
- Build tool for modern web applications
- Used for Frontend development

---

## Y

**YOLO**
- You Only Look Once
- Real-time object detection algorithm
- Used for detecting persons, phones, and other objects

**YOLO Pose**
- Variant of YOLO for pose estimation
- Detects 17 COCO keypoints per person

**Yaw**
- Horizontal rotation angle of the head
- Part of head pose estimation

---

## 6

**6DRepNet**
- 6 Degrees of Freedom RepNet
- Head pose estimation model
- Estimates yaw, pitch, and roll angles
